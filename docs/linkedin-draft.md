# Rascunho de apresentação

Pathboard: planejador de projetos com Python, FastAPI, Vue 3 e TypeScript.

A aplicação conecta tarefas por dependências, calcula o caminho crítico e permite simular uma nova estimativa sem alterar o plano salvo. A ideia é mostrar quais mudanças afetam a duração do projeto e quais cabem na folga de uma tarefa.

O backend rejeita ciclos e protege atualizações concorrentes com versões. O repositório inclui testes dos cálculos, testes de navegador, documentação OpenAPI e instruções para executar localmente.

Código: https://github.com/SamirGedeon/pathboard
